Steps to build aquabox Android application

On Windows:
1. Download aquabox-frontend source files 
2. Start Docker Desktop
3. Start Visual Studio Code
4. In the Visual Studio Code start a new terminal window and go to aquabox-frontend folder
5. run ./run_ionic_env.cmd
6. from the Docker container run ./build.sh
7. the app-debug.apk file will be created in android/app/build/outputs/apk/debug folder
